# Engineering Playbook

This repository follows the engineering standards documented in this directory.

Read every markdown document before generating code.
- Markdown documents can be found in the .ai folder and seperated by subject

These documents define:

- Architecture
- Folder structure
- Technology stack
- Coding standards
- AI behaviour
- Project conventions

When generating code:

- Follow these standards.
- Do not introduce new patterns unless asked.
- Prefer consistency over novelty.
- If you want to do something outside of the playbook, ask before proceeding.
